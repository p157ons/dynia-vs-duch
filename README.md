# Dynia vs Duch

Halloweenowe kółko i krzyżyk w przeglądarce. Dynia to krzyżyk, Duch to kółko.

- Gra z komputerem (Łatwy / Średni / Trudny) albo we dwoje
- Licznik wygranych i remisów, zmiana gracza rozpoczynającego co rundę
- Dźwięki generowane w przeglądarce (Web Audio), z przyciskiem wyciszania
- Jeden plik `index.html`, bez zależności

**Zagraj:** https://p157ons.github.io/dynia-vs-duch/
